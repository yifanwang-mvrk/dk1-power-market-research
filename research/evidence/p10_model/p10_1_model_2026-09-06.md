# P10.1 — Logistic Regression and Calibration (development only)

**Status:** complete — 2026-09-06
**Scope:** model and calibration fit inside development; **the holdout is not read**
**Holdout:** LOCKED AND UNUSED

## Frozen specification

- Model: multinomial LogisticRegression (lbfgs), class_weight=balanced; selected `C = 1.0` from
  [0.05, 0.1, 0.25, 0.5, 1.0] by calibration-slice macro-F1 (the grid is nearly
  flat — the features carry little signal).
- Calibration: sigmoid, CalibratedClassifierCV on the frozen model, fit on the calibration slice only (selected as the lower-Brier of sigmoid and isotonic).
- Features (decision-eligible): ['wind_revision_mwh', 'wind_forecast_5h_mwh', 'wind_revision_when_low_wind_mwh', 'solar_revision_mwh', 'residual_load_known_mwh', 'hour_sin', 'hour_cos', 'doy_sin', 'doy_cos', 'is_weekend'].
- Target: the frozen three-class label; `delta = 5.9956075` is **not**
  re-estimated.

## What the model learned

Standardized coefficient sign checks against the H1 / H2 mechanisms:

| Term | Coefficient | Expected | Matches |
|---|---:|:--:|:--:|
| DOWN:wind_revision_mwh | +0.156 | + | yes |
| DOWN:wind_forecast_5h_mwh | -0.251 | - | yes |
| DOWN:residual_load_known_mwh | -0.358 | - | yes |
| UP:wind_revision_mwh | -0.164 | - | yes |
| UP:residual_load_known_mwh | +0.196 | + | yes |

**The coefficient signs match the H1/H2 mechanisms for 5 of 5 checked terms, but on the 2024 H1 development validation slice there is no edge: the class-weighted argmax reaches balanced accuracy 0.354 (vs 0.333 chance), and after calibration the argmax collapses to the majority class (0.333, equal to majority 0.333). Calibrated probabilities are no better than train-frequency climatology on this slice. This is consistent with P4.4 -- 2024 H1 is where the H2 gradient did not reproduce. The Level C holdout report will present both the raw and the calibrated predictions.**

## Limitations

- Development-only. The validation slice is 2024 H1 — the same window where the
  H2 gradient did not reproduce (P4.4), so a weak validation result is expected
  and is itself informative.
- The model inherits every upstream weakness (small effect sizes, no
  demand-shock information).
